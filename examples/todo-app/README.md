# todo-app example

Demonstrates the full anvil-bellows pipeline:

```
@Controller source files
    ↓ anvil-bellows
routes.module.ts          (generated, checked in)
    ↓ anvil-bellows-openapi
openapi.json              (generated, checked in)
    ↓ @hey-api/openapi-ts
src/api/                  (generated, checked in)
    ↓ React + TanStack Query
Todo UI
```

## Running

You need two terminals:

```bash
# Terminal 1 — API server (port 3001)
pnpm dev:server

# Terminal 2 — Vite dev server (port 5173)
pnpm dev:client
```

Open http://localhost:5173.

## Re-generating

If you change the controller, re-run:

```bash
pnpm generate
```

This regenerates `routes.module.ts`, `openapi.json`, and `src/api/`.

## Structure

```
server/src/
  todo-service.ts       in-memory store
  todo-controller.ts    @Controller with Zod schemas
  routes.module.ts      GENERATED by anvil-bellows
  server.ts             Express server

src/
  api/                  GENERATED by @hey-api/openapi-ts
  components/
    AddTodo.tsx
    TodoList.tsx
    TodoItem.tsx
  App.tsx
  main.tsx
```
